# Adithya V Portfolio

A responsive dark portfolio built with React, Vite, Tailwind CSS, Framer Motion, Lucide React, and React Icons.

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Content

Portfolio content is managed in `src/utils/profile.js`. Resume download is served from `public/Adithya_V_Resume.docx`.
